# Sortie custom artwork

Created with the built-in image-generation tool on 2026-09-26 for the mobile app. These are fictional editorial images, not photographs of a specific unit, base, cadet or official course event. No user records were supplied to the image model.

Production copies: `sortie-horizon.jpg`, `sortie-journal.jpg`, `sortie-terrain.jpg`. Images are resized and JPEG-compressed for the offline app; original generated PNGs remain in the local generated-images folder. Cropping and theme adjustments happen in CSS. Essential labels and all report data remain real HTML text.
